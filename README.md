# تنزيل سريع — Fast Downloader

تطبيق Flutter متعدد المنصات لتنزيل الملفات من رابط مباشر، مع **استئناف تلقائي** من آخر نقطة وصل إليها التنزيل إذا انقطع الإنترنت ثم عاد.

## المنصات المدعومة

- Android
- iOS
- Web
- Windows
- macOS
- Linux

## المميزات

- تنزيل بثّ متواصل (Streaming) دون تحميل الملف كاملاً في الذاكرة على المنصات الأصلية.
- استئناف عبر ترويسة `Range: bytes=<offset>-` بعد انقطاع الاتصال.
- إعادة محاولة تلقائية بفاصل متصاعد (Backoff) حتى رجوع الاتصال، وإعادة فورية عند اكتشاف عودة الإنترنت عبر `connectivity_plus`.
- كشف الانقطاع الصامت (عدم وصول بيانات لمدة 20 ثانية).
- إيقاف مؤقت / متابعة / إلغاء وحذف الملف الجزئي.
- عرض التقدم، الحجم، السرعة، والوقت المتبقي.

## التشغيل

```bash
cd code/fast_downloader
flutter pub get
flutter run                    # المنصة الحالية
flutter run -d chrome          # الويب

flutter run                    # مع جهاز/محاكي أندرويد أو آيفون متصل
```

## أين تُحفظ الملفات؟

- على الهاتف وسطح المكتب: داخل مجلد `downloads` في مجلد مستندات التطبيق الذي يوفره `path_provider`. يظهر المسار الكامل في بطاقة التنزيل بعد الاكتمال ويمكن نسخه.
- على الويب: تُجمع البيانات في الذاكرة ثم يُحفظ الملف عبر المتصفح عند الاكتمال (لا يمكن استئنافه بعد إغلاق الصفحة على الويب).

## كيف يعمل الاستئناف؟

1. قبل كل محاولة تُقرأ نهاية الملف المخزن لمعرفة عدد البايتات المحفوظة.
2. يُرسل طلب `GET` مع `Range: bytes=<offset>-`.
3. إذا ردّ الخادم بـ `206 Partial Content` تُضاف البيانات إلى نهاية الملف.
4. إذا ردّ بـ `200 OK` أو `416` بشكل غير متوقع يُعاد ضبط الملف والبدء من الصفر لضمان سلامته.
5. عند أي خطأ يُعاد جدولة المحاولة، وعند عودة الإنترنت تُستأنف فوراً.

> ملاحظة: الاستئناف يحتاج خادماً يدعم طلبات Range (معظم خوادم الملفات والـ CDN تدعمها). على iOS قد تحتاج روابط `http` إلى تعديل إعدادات ATS؛ يُفضّل استخدام `https`.

### استكشاف أخطاء أندرويد
إذا طلب Gradle تثبيت NDK (`Preferred NDK version is '28.2.13676358'`)، ثبّته من Android Studio → SDK Manager → SDK Tools → NDK. هذا مطلوب من AGP 9 حتى دون كود أصلي في التطبيق.
